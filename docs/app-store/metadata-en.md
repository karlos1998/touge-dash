## Description

Touge Dash is an independent telemetry dashboard and drive recorder for compatible Bluetooth interfaces working with an ECUMaster EMU Black ECU.

Key engine data is clear from the moment the app launches. Touge Dash automatically finds a remembered EMULOGGER and displays oil temperature and pressure, coolant temperature, boost, AFR, RPM, speed and other useful parameters.

DRIVE HISTORY

Every drive can be recorded locally on the device. Interactive charts place all parameters on one timeline, while optional GPS recording shows the route and the location of the selected sample.

TOUGE DASH CLOUD

An account is optional — the dashboard and local history also work without signing in. When sync is enabled, drives recorded offline are uploaded after the internet connection returns and become available in the web dashboard. You can grant another user, such as a mechanic, access to a vehicle, export a drive or share it with a secure link.

ALWAYS WITHIN REACH

Live Activity keeps essential values available on the Lock Screen and in supported CarPlay views. The Apple Watch app displays temperatures, oil pressure, boost and AFR. iPhone and Apple Watch can warn you when oil or coolant temperature exceeds the configured threshold.

FEATURES

• automatic discovery of a compatible BLE interface,
• adaptive dashboard for iPhone and iPad,
• local drive history and interactive charts,
• optional GPS route recording,
• optional cloud sync and web dashboard,
• Live Activity, widgets and Apple Watch app,
• oil and coolant temperature alerts,
• Bluetooth connection diagnostics.

Touge Dash is not a certified measuring instrument. Before using it while driving, compare its readings with the ECU manufacturer's software and do not interact with the app in a way that distracts you from the road.

Touge Dash is an independent project and is not affiliated with or authorised by ECUMaster.
